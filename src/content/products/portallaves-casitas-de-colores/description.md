Una callecita de casitas de colores para recibirte cada vez que llegas a casa. Cada una tiene su puerta, sus ventanitas y su propio tono, y abajo esperan los ganchos para que las llaves siempre tengan dónde quedarse. Como se pinta a mano, cada portallaves sale distinto: un detalle alegre para la entrada, hecho con ese cariño que se nota en cada trazo.
